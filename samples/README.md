# Sample files for testing

- `sample-resume.pdf` — a **made-up** resume (Asha Rao, a fictional data engineer). Use it whenever you test with
  free trial AI models (NVIDIA): their terms forbid sending personal data, so never upload a real resume in that mode.

For a job posting, open any public job ad (for example on Greenhouse, Lever or Ashby) and click the extension's
toolbar icon. Public job ads aren't personal data.
